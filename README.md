## 🚀 Tech Stack

This project is built using a modern, fast, and responsive frontend stack:

- **Framework:** React 18 (with Vite for fast bundling)
- **Language:** TypeScript (for type safety and clean code)
- **Styling:** Tailwind CSS (for modern utilities)
- **Animations:** Framer Motion (for fluid transitions)
- **Icons:** Lucide React

---

## ✨ Features

- 📱 **Fully Responsive Layout** – Optimized flawlessly for Mobile, Tablet, and Desktop screens.
- 🎨 **Modern UI/UX** – Clean aesthetics featuring smooth animations and micro-interactions.
- 💻 **Project Showcase** – Visual grid highlighting key applications, live links, and codebases.
- 🛠️ **Technical Skills** – Organized breakdown of programming languages, tools, and frameworks.
- 📜 **Certifications** – Verified credentials in core computer science domains.
- 📄 **Resume Download** – Directly accessible resume path for recruiters.
- 📧 **Contact Section** – Interactive form and links to reach out instantly.
