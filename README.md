## 🚀 Tech Stack

This project is built using a modern, fast, and responsive frontend stack:

- **Framework:** React 18 (with Vite for fast bundling)
- **Language:** TypeScript (for type safety and clean code)
- **Styling:** Tailwind CSS (for modern utilities)
- **Animations:** Framer Motion (for fluid transitions)
- **Icons:** Lucide React
